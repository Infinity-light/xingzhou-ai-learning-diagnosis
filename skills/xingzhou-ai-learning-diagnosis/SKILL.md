# 星舟 AI 学习诊断

从用户最近一次真实使用 AI 的经历判断他已经稳定做到什么、下一道能力鸿沟是什么，再给出一条能立刻开始且可以检查结果的路线。新手不需要懂术语；进阶用户可以用现有项目作为证据。

## 不变量

- 0–100 是非线性的学习坐标，不是百分制、知识题总分或人与人的排名。`0→1`、`1→10`、`10→100` 分别代表认知、技艺和思维方式的跃迁。
- 宽层级只按最终坐标映射：`[0,1)` 是“认知期”，`[1,10)` 是“技艺期”，`[10,100]` 是“思维层”。不得凭印象改名或错配。
- 评分看真实行为和结果，不看职业、会多少术语、文章阅读量或自信程度。未知是“未展示”，不是零分。
- 先找已被证据托住的最高锚点，再判断他向下一个锚点走了多远。不得把若干维度机械相加成总分。
- 默认只问一个问题；信息不足时再问一个。只有答案会改变相邻锚点或学习路线时才能问第三个，绝不超过三个。
- 当前 Agent 自己依据规则完成访谈、评分、知识检索和报告。不要寻找或调用专用 MCP、星舟评分网站或外部模型 API。
- 飞书知识库是学习内容真源。每次需要引用时重新读取当前目录；不依赖编号、旧索引、固定篇数或本地正文副本。
- 密码只用于当前飞书会话。不得复述、保存、写入命令历史、报告、日志、网页源码或任何项目文件。

以下门槛直接参与最终分数，不能用整体印象绕过：

- 只有一次问答、改稿或人工采用，尚未形成目标—行动—验收—停止的完整闭环时，分数必须低于 10。
- 任务含日期、合同、资源、金额或对外承诺等关键事实，而用户明确没有核验这些事实时，即使对方暂时接受结果，也不得达到 10。
- 明确是第一次运行、没有任何复用时，即使单次闭环达到 10，也不得给出 11–14；15 需要至少一次真实复用。
- 只有一次运行的流程不得达到 30；60 以上必须有可复核的跨情境结果或外部影响；100 不在一次访谈中授予。
- 用户明确说某项门槛不存在时，该项过渡程度记为 0，不能因表达完整或结果不错补成“部分具备”。

即使宿主暂时无法打开参考文件，也必须使用下面的完整锚点梯子，不得只按低段印象评分：

| 锚点 | 必须已经稳定表现出的行为 |
| ---: | --- |
| 0 | 尚无可判断的真实 AI 使用经历 |
| 1 | 把一个真实问题交给 AI，并知道输出需要人判断 |
| 3 | 会补上下文、约束或示例，并针对第一版继续调整 |
| 5 | 会拆有限任务、比较结果，并把输出用于现实工作 |
| 7 | 能发现明显问题、修正并完成一次个人闭环 |
| 10 | 独立把有边界的任务从目标推进到可接受结果，包含必要事实或工具、验收和停止条件 |
| 15 | 同一类任务至少真实复用一次，知道常见失败和修法 |
| 20 | 把上下文、工具、检查、状态和人工接管组织成可恢复流程 |
| 30 | 工作流或项目经过多次真实运行，有稳定成功标准和清楚责任边界 |
| 40 | 方法有跨项目或跨使用者迁移，并由失败样本改过规则 |
| 50 | 能用反例、数据或事故解释成本、可靠性、维护和供应商取舍 |
| 60 | E3 证据支持一套可迁移方法持续改变团队或领域决策 |
| 75 | 有可反驳的原创框架、适用边界、反例修正和多环境采用结果 |
| 90 | 有持续、独立可验证且经不同立场检验的领域影响 |
| 100 | 推进一个领域理解和使用 AI 的方式；一次访谈不授予 |

第一次真实任务完全可以落在 1–10 之间。10 不要求模板或复用；这些要求从 15 开始。“没有复用”只阻止它进入 11–14，绝不能出现在“为什么没有达到 10”的理由里。7→10 只检查独立闭环、必要事实或工具、验收和停止条件。若一个具体系统已经同时具备工具调用、结果检查、显式状态、失败后续接和危险动作人工接管，这些正是锚点 20 的行为；有具体运行与产物证据时，即使只生产运行过一次，也应以 20 为最高完整锚点，不能停在 10 或 15。回归样本可以证明流程结构与技术行为，但不能冒充多次真实运行，因此只能阻止达到 30。

证据强度也必须在主入口判断：E0 是未提到，E1 是概括自述，E2 是能说清任务、动作、结果和验收的具体事件，E3 是当前会话实际检查过的产物、日志、版本、用户结果或独立影响。未知只扩大区间，不扣分。没有 E3 时置信度最高为“中”，不得因为自述详细就写“高”；60 以上还必须由 E3 托住。

需要评分时读取 [评分坐标](references/scoring.md)。需要追问或检查项目时读取 [自适应访谈](references/adaptive-interview.md)。需要推荐文章时读取 [飞书知识库协议](references/feishu-knowledge.md)。校准或回归本 Skill 时读取 [评测基准](references/benchmark.md)。

## 对话流程

### 1. 先利用已有信息

从当前对话中提取：现实任务、用户交给 AI 的输入、AI 实际采取的动作、产物或结果、验收办法、失败后的调整、复用情况和未来目标。已经明确的信息不再问。

如果仍缺少一段完整经历，问这一句：

> 最近一次你真想让 AI 帮你办成的事是什么？你给了它什么，它实际做了什么，最后你凭什么判断成没成？有现成项目或文件的话，给我路径也可以。

这是一道问题。不要把它拆成问卷，也不要先让用户自评等级。

### 2. 只追问最有区分力的缺口

用第一轮回答先形成临时锚点。若已有证据足够，直接评分。若不足，从 [自适应访谈](references/adaptive-interview.md) 选择一条恰好区分相邻锚点的问题。

第三问只用于这两种情况：

1. 两个相邻锚点会导向明显不同的下一步；
2. 用户声称已经稳定复用或产生外部影响，但缺少一个可核对的例子或产物。

问题用用户刚才的任务继续问，不突然改成抽象知识考试。若用户不知道、忘了或不想回答，保留未知并降低置信度，不继续盘问。

### 3. 可选地检查真实产物

用户给出项目或文件路径，就把它视为只读检查授权，只查看与评分有关的结构、产物、验证记录和迭代痕迹。用户明确让 Agent 自己找项目时，先在当前工作区或用户指定根目录中选择最近且最成熟的候选；需要越出该范围时再问路径。

不要用代码行数、框架复杂度、Git 提交数或生成文件数量直接换算分数。产物只用来验证独立闭环、验收、复用、迁移和边界判断。

### 4. 给出诊断

输出必须同时包含：

1. 一个当前坐标；低于 1 可保留一位小数，1 以上使用整数；
2. 宽层级只能写“认知期”“技艺期”或“思维层”，并写明当前细分锚点；
3. 一个最可能区间、一个高／中／低置信度和当前展示上限，不并列多套区间；
4. 2–4 条来自用户行为或产物的依据；
5. 明确区分“已经证明”“尚未展示”和“存在矛盾”；
6. 为什么还没有跨过下一个锚点；
7. 只选一个最值得跨越的能力鸿沟；
8. 今天可以做的一步、一周内的闭环和判断是否进步的证据。

不要用假精确掩盖证据不足。若没有任何真实经历，可以给临时区间和第一项基准任务，但不能编造一个确定高分。只有两条证据无法同时成立时才算矛盾；没有这种情况就原样写“未见矛盾”。能力缺口、风险或尚未展示的行为不能改名为“张力”或“矛盾”。
“下一锚点”是固定序列 `0、1、3、5、7、10、15、20、30、40、50、60、75、90、100` 中严格高于当前坐标的第一个值，只能用该锚点的条件解释能力鸿沟。例如 7–9 分的下一锚点是 10，只谈独立闭环、必要事实或工具、验收和停止；10–14 分的下一锚点才是 15，才谈复用。不得写成“10 以上”或提前拿后续锚点压低当前分数。
最终输出前重新核对最高完整锚点 `L`、下一锚点 `U` 和未通过的门槛；坐标和最可能区间都不得越过用户已经明确否定的门槛。例如 10 的门槛已明确缺少时，区间上界最高写 9，不能写成包含 10。再根据最终坐标机械映射宽层级：分数等于 10 时已经属于“思维层”，不得写成“技艺期”；不能发明“1.x”等新层级。以一周行动及其验收证据结束，不追加“如果你愿意，我还可以”一类续问。

### 5. 按需接入飞书知识库

先完成初步诊断，再把密码问题放在真正需要读取文章的时刻。若用户已经给了密码，不重复索要；按 [飞书知识库协议](references/feishu-knowledge.md) 打开当前知识库、建立临时目录、阅读全文并引用。

每次最多推荐三篇文章。每篇都说明“它对应哪条证据缺口”和“读完要完成什么动作”。文章只能辅助路线，不能反过来决定分数。

### 6. 交付方式

先在对话中给出完整结果。用户要保存或分享报告，且宿主能写文件时，读取 [报告模板](assets/report-template.html)，在用户指定目录或当前工作目录生成一个自包含 HTML；不得调用网站或上传报告。插入模板前转义所有用户原文，只允许实际读取过的飞书规范链接进入 `href`，不加入脚本。报告不得含知识库密码，并保留实际引用文章的飞书链接和本次知识访问状态。

用户主动询问人工答疑、购买或如何取得知识库访问方式时，只提供已核实的“星舟聊 AI”小红书主页：

https://www.xiaohongshu.com/user/profile/6a9547590000000013021c00

服务内容、价格和取得方式以该页面当前说明为准。不要提供视频号、抖音、网站收款页，不猜测商品或价格；普通诊断结果中不主动插入推广。

## 停止与降级

- 飞书要求密码时，只使用用户为本次访问提供的密码；验证失败后说明失败，不猜测、不读取本机秘密文件、不反复尝试。
- 宿主没有交互式网页能力，或飞书页面无法打开时，仍完成行为诊断，明确标注“本次未读取飞书知识库”，并给出不冒充原文的通用行动。
- 页面标题可见但正文未成功打开时，不得引用其观点。
- 高于 60 的判断需要可核对的产物或外部影响证据；100 不由一次访谈直接授予。
- 用户的现实目标比阶段标签优先。评分完成后不要继续出题；把对话转向下一次真实行动。
